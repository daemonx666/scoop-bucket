# daemonx666/scoop-bucket

Scoop bucket for [Code Speed](https://github.com/daemonx666/code-speed): live token speed, usage, cost and quotas of your coding agents.

```powershell
scoop bucket add code-speed https://github.com/daemonx666/scoop-bucket
scoop install code-speed
```

The manifest is updated by the code-speed release workflow; please open issues there.
